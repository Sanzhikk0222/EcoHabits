# EcoHabits

Оқушылар мен жастарға арналған эко-әдет қосымшасы: күнделікті, апталық және айлық тапсырма, фотоесеп, XP, өсетін өсімдік, рейтинг. Интерфейс қазақша және орысша. Статикалық SPA (HTML + Tailwind CDN + JavaScript), backend ретінде Supabase.

## Файлдар

- `index.html`: бүкіл қосымша
- `config.js`: Supabase URL мен публичный кілт (тек осы файлды толтырасың)
- `supabase_schema.sql`: кестелер, RLS, триггер, `complete_quest` және `ensure_profile` функциялары

`index.html` пен `config.js` міндетті түрде бір папкада (репозиторий түбірінде) тұруы керек.

## Іске қосу

1. [supabase.com](https://supabase.com) бөлімінде жоба аш.
2. SQL Editor ішінде `supabase_schema.sql` мазмұнын толық іске қос. Файлды қайта іске қосуға болады: ескі деректер сақталады, апталық және айлық тапсырмалар қосылады.
3. Project Settings → API бөлімінен **Project URL** мен **Publishable (anon)** кілтін көшір.
4. `config.js` ішіне екеуін жаз. `secret` / `service_role` кілтін ешқашан қоспа.
5. Authentication → Providers → **Google** қос (Google Cloud Console-да OAuth Client ID жасап, Client ID мен Secret-ті Supabase-ке енгіз).
6. Authentication → URL Configuration: **Site URL** мен **Redirect URLs** ішіне сайттың толық мекенжайын қос (мысалы `https://логин.github.io/EcoHabits/`).
7. Жергілікті тексеру: `npx serve .` немесе VS Code Live Server. Файлды `file://` арқылы ашпа.

Хакатонда email растауды жылдамдату үшін Authentication → Providers → Email бөлімінде «Confirm email» опциясын уақытша өшіруге болады.

## Тапсырмалар

| Түрі | Саны | XP | Қашан жаңарады |
| --- | --- | --- | --- |
| Күнделікті | 6 | 50 | Ертеңіне |
| Апталық | 3 | 150 | Дүйсенбіде |
| Айлық | 3 | 400 | Айдың 1-інде |

Күн, апта және ай `Asia/Almaty` уақытымен есептеледі. Кез келген тапсырма сол күнгі серияны жалғастырады. XP мөлшері мен тізім `quest_defs` кестесінде тұр, жаңа тапсырма қосқың келсе, сол жерге жол қосып, `index.html` ішіндегі `QUESTS` тізіміне де қос.

## Тіл

Оң жақ жоғарыдағы ҚАЗ / РУС батырмасы тілді ауыстырады. Таңдау браузерде сақталады. Бірінші ашқанда браузердің тіліне қарайды. Барлық мәтін `index.html` ішіндегі `DICT` нысанында тұр.

## Фотоны тексеру қалай істейді

Тапсырмадағы «Фото есеп жіберу» батырмасы сайттың өз камерасын ашады (телефонда артқы камера, ноутбукта вебкамера). Суретті сол жерде түсіресің, сондықтан галереядағы не интернеттен алынған сурет мұнда өтпейді. Камераға рұқсат сұралады, сайт HTTPS арқылы ашылуы керек.

Түсірілген кадр бес тексеруден өтеді:

1. Пішім мен өлшем (кемінде 300 px).
2. **Түпнұсқасын тексеру.** Камерадан түсірілген кадр үшін бұл қадам өтеді. Камера ашылмаса, камера терезесіндегі «Файлмен жүктеу» батырмасы бар, бірақ файл жүктеуде қатаң ереже: сайт JPEG ішіндегі EXIF деректерін оқиды. Суретте камера (`Make` / `Model`) және түсірілген уақыт (`DateTimeOriginal`) болуы керек. Интернеттен жүктелген сурет, скриншот, мессенджерден келген файл, PNG және WebP мұндай деректі әдетте сақтамайды, сондықтан қабылданбайды. Түсірілген уақыт тапсырма мерзіміне сәйкес болуы керек: күнделікті үшін 36 сағат, апталық үшін 8 күн, айлық үшін 32 күн. Photoshop, GIMP, Canva сияқты редактормен өңделген суретті де қабылдамайды. Файл атауы (`stock`, `unsplash`, `screenshot` т.б.) да қаралады.
3. SHA-256 және dHash таңбасы жасалады.
4. **Мазмұн тексеру.** CLIP моделі (Transformers.js, `Xenova/clip-vit-base-patch32`) браузердің ішінде суретті тапсырмаға қатысты сипаттамалармен және «қатысы жоқ» топтармен (отырған адам, скриншот, кездейсоқ нәрсе) салыстырады. Тапсырманың өз тобы жеңіп, ұпайы `SCORING.MIN_SCORE` (0.35) шегінен асса ғана сурет өтеді. Нәтиже кестесі браузер консолінде (`F12`) көрінеді.
5. Сервер таңбаны салыстырады: дәл көшірме кез келген қолданушыда бұғатталады. Ұқсас сурет басқа қолданушыда (айырмасы 6 битке дейін) бұғатталады, ал өз суреттеріңде тек өте ұқсас көшірме (2 битке дейін) бұғатталады. Сондықтан бір бұрышпен түсірілген кранды күнде түсіре беруге болады.

Қабылданбаған сурет үшін экранда себебі де жазылады (камера деректері жоқ, сурет ескі, өңделген т.б.).

Модельді алғашқы жүктеу шамамен 150 МБ (бір рет, кейін браузер кэшінде сақталады). Тапсырмалар бетін ашқанда ол фонда жүктеле бастайды. Ұялы желіде не «трафикті үнемдеу» режимінде фондағы жүктеу өшірулі.

## Қалай жұмыс істейді

- XP мен серияны тек сервердегі `complete_quest()` өзгертеді. Клиент `profiles` кестесінде тек `username` бағанын (бір рет) жаза алады.
- Серия: күніне кемінде бір тапсырма жасасаң, +1. Бір тәуліктен астам үзіліс болса, жаңа тапсырмадан кейін серия 1-ден басталады.
- Суреттің өзі сақталмайды, тек оның таңбасы (хэш) сақталады.

## Белгілі шектеулер

- Барлық фото тексеру браузерде жүреді, сондықтан біліктірек адам оны айналып өтіп, `complete_quest` функциясын тікелей шақыра алады. EXIF деректерін арнайы құралмен жалғандауға да болады. Шынайы қорғаныс үшін тексеруді Supabase Edge Function-ға көшіру керек.
- Камера деректері бар сурет те «жаңа» бола бермейді: біреудің экранын телефонмен түсіріп жіберу мүмкін. Мұны ішінара ғана CLIP (экран тобы) ұстайды.
- Файлмен жүктеу жолында телефондағы кейбір браузерлер немесе мессенджерлер EXIF-ті жояды, сондықтан сурет қабылданбауы мүмкін. Негізгі жол сайттың өз камерасы.
- Instagram, Telegram сияқты қолданбалардың ішкі браузерінде камера ашылмауы мүмкін. Сайтты Chrome не Safari-де аш.
- Мазмұн тексеруі кранның бар екенін көреді, бірақ оны дәл сен жапқаныңды дәлелдей алмайды.
- Марапаттар дүкені әзірге «Жақында…» күйінде.
