# EcoHabits

Оқушылар мен жастарға арналған эко-әдет қосымшасы: күнделікті тапсырма, фотоесеп, XP, өсетін өсімдік, рейтинг. Бір файлды SPA (HTML + Tailwind CDN + JavaScript), backend ретінде Supabase.

## Файлдар

- `index.html`: бүкіл қосымша
- `supabase_schema.sql`: кестелер, RLS, триггер, `complete_quest` функциясы

## Іске қосу

1. [supabase.com](https://supabase.com) бөлімінде жоба аш.
2. SQL Editor ішінде `supabase_schema.sql` мазмұнын толық іске қос.
3. Project Settings → API бөлімінен **Project URL** мен **anon public** кілтін көшір.
4. `index.html` ішіндегі `CONFIG.SUPABASE_URL` және `CONFIG.SUPABASE_ANON_KEY` мәндерін ауыстыр. Anon кілті браузерге арналған, қауіпсіздікті RLS қамтамасыз етеді. `service_role` кілтін ешқашан кодқа қоспа.
5. Authentication → Providers → **Google** қос (Google Cloud Console-да OAuth Client ID жасап, Client ID мен Secret-ті Supabase-ке енгіз).
6. Authentication → URL Configuration:
   - **Site URL**: сайтыңның мекенжайы (мысалы `https://ecohabits.vercel.app`)
   - **Redirect URLs**: сол мекенжай және жергілікті тест үшін `http://localhost:5500` (өз портыңды қой)
7. Жергілікті тексеру: `npx serve .` немесе VS Code Live Server. Файлды `file://` арқылы ашпа, OAuth және хэштеу істемейді.

Хакатонда email растауды жылдамдату үшін Authentication → Providers → Email бөлімінде «Confirm email» опциясын уақытша өшіруге болады.

## Vercel-ге шығару

GitHub-қа репозиторий жүкте, Vercel-де «Import Project» жаса. Framework: **Other**, build командасы жоқ. Статикалық файл бірден жұмыс істейді.

## Қалай жұмыс істейді

- XP мен серияны тек сервердегі `complete_quest()` өзгертеді. Клиент `profiles` кестесінде тек `username` бағанын (бір рет) жаза алады.
- Серия күні `Asia/Almaty` белдеуі бойынша есептеледі. Бүгін алғашқы тапсырма: серия +1. Кешегі күні белсенділік болмаса: серия 1-ден қайта басталады, ал интерфейс бір тәуліктен астам үзілісте 0 көрсетеді.
- Anti-cheat: SHA-256 мен dHash серверде барлық қолданушылар бойынша салыстырылады (дәл және ұқсас көшірмелер бұғатталады). «Интернеттен алынған» деген тексеру әзірше эвристика (файл атауы, түсірілген уақыт). Нақты AI-модель қосу үшін серверлік функция (мысалы Supabase Edge Function) керек болады.
- Суреттің өзі сақталмайды, тек оның таңбасы (хэш) сақталады.

## Белгілі шектеулер

- Марапаттар дүкені әзірге «Жақында…» күйінде.
- `file.lastModified` кейбір браузерлерде түсірілген уақытты дәл бермеуі мүмкін, сондықтан ескі суреттерді қабылдамау ережесі 36 сағатпен шектелген.
