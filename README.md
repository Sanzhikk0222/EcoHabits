# EcoHabits

Оқушылар мен жастарға арналған эко-әдет қосымшасы: күнделікті тапсырма, фотоесеп, XP, өсетін өсімдік, рейтинг. Статикалық SPA (HTML + Tailwind CDN + JavaScript), backend ретінде Supabase.

## Файлдар

- `index.html`: бүкіл қосымша
- `config.js`: Supabase URL мен публичный кілт (тек осы файлды толтырасың)
- `supabase_schema.sql`: кестелер, RLS, триггер, `complete_quest` және `ensure_profile` функциялары

`index.html` пен `config.js` міндетті түрде бір папкада (репозиторий түбірінде) тұруы керек.

## Іске қосу

1. [supabase.com](https://supabase.com) бөлімінде жоба аш.
2. SQL Editor ішінде `supabase_schema.sql` мазмұнын толық іске қос.
3. Project Settings → API бөлімінен **Project URL** мен **Publishable (anon)** кілтін көшір.
4. `config.js` ішіне екеуін жаз. `secret` / `service_role` кілтін ешқашан қоспа.
5. Authentication → Providers → **Google** қос (Google Cloud Console-да OAuth Client ID жасап, Client ID мен Secret-ті Supabase-ке енгіз).
6. Authentication → URL Configuration: **Site URL** мен **Redirect URLs** ішіне сайттың толық мекенжайын қос (мысалы `https://логин.github.io/EcoHabits/`).
7. Жергілікті тексеру: `npx serve .` немесе VS Code Live Server. Файлды `file://` арқылы ашпа.

Хакатонда email растауды жылдамдату үшін Authentication → Providers → Email бөлімінде «Confirm email» опциясын уақытша өшіруге болады.

## Фотоны тексеру қалай істейді

Сурет жүктелгенде бес тексеру өтеді:

1. Пішім, өлшем (12 МБ-тан аспасын, кемінде 300 px).
2. Файл атауы (`stock`, `unsplash` т.б. болмасын) және түсірілген уақыты (36 сағаттан ескі болмасын).
3. SHA-256 және dHash таңбасы жасалады.
4. **Мазмұн тексеру.** CLIP моделі (Transformers.js, `Xenova/clip-vit-base-patch32`) браузердің ішінде суретті тапсырмаға қатысты сипаттамалармен және «қатысы жоқ» топтармен (отырған адам, скриншот, кездейсоқ нәрсе) салыстырады. Тапсырманың өз тобы жеңіп, ұпайы `SCORING.MIN_SCORE` (0.35) шегінен асса ғана сурет өтеді. Нәтиже кестесі браузер консолінде (`F12`) көрінеді, шекті сол кестеге қарап реттеуге болады.
5. Сервер таңбаны барлық қолданушылар бойынша салыстырады: дәл және ұқсас көшірмелер бұғатталады.

Модельді алғашқы жүктеу шамамен 150 МБ (бір рет, кейін браузер кэшінде сақталады). Тапсырмалар бетін ашқанда ол фонда жүктеле бастайды. Ұялы желіде не «трафикті үнемдеу» режимінде фондағы жүктеу өшірулі.

## Қалай жұмыс істейді

- XP мен серияны тек сервердегі `complete_quest()` өзгертеді. Клиент `profiles` кестесінде тек `username` бағанын (бір рет) жаза алады.
- Серия күні `Asia/Almaty` белдеуі бойынша есептеледі. Бүгін алғашқы тапсырма: серия +1. Бір тәуліктен астам үзіліс болса, жаңа тапсырмадан кейін серия 1-ден қайта басталады.
- Суреттің өзі сақталмайды, тек оның таңбасы (хэш) сақталады.

## Белгілі шектеулер

- Мазмұн тексеруі браузерде жүреді, сондықтан біліктірек адам оны айналып өтіп, `complete_quest` функциясын тікелей шақыра алады. Шынайы қорғаныс үшін тексеруді Supabase Edge Function-ға көшіру керек.
- CLIP суретте кран бар-жоғын көреді, бірақ оны дәл сен жапқаныңды дәлелдей алмайды. Интернеттен алынған, бірақ кранды көрсететін жаңа сурет те өтіп кетуі мүмкін (дубликат тексеруі тек бұрын жүктелген суреттерді ұстайды).
- Ескі суреттерді қабылдамау ережесі файлдың өзгертілген уақытына сүйенеді (36 сағат). Галереядан ескі сурет таңдасаң, ол қабылданбайды.
- Марапаттар дүкені әзірге «Жақында…» күйінде.
